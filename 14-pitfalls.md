# Common Pitfalls - SC-300

> Frequent confusions, traps, and "gotchas" that cause wrong answers on the exam.

### Forgetting break-glass accounts

Always exclude two emergency accounts from CA + monitor heavily.

### Confusing user risk vs sign-in risk

User = identity compromised over time. Sign-in = single anomalous event.

### Using federation by default

PHS is the recommended default; federation only for specific reqs.

### Mixing CA assignments and CTAS

CTAS is tenant-wide trust posture; CA is per-policy. Different layers.

### Granting all admin consent

Many permissions can be user-consented - reduce admin consent surface.
