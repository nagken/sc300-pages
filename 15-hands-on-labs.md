# Hands-On Labs - SC-300

> Free-tier or trial labs you can run end-to-end in 30-60 minutes.

### 1. Configure your first CA policy

Block legacy auth + require MFA for all users (report-only first).

### 2. Enable PIM for Global Admin

Convert Global Admin assignments to eligible. Configure activation = require MFA + ticket reason + 4-hour max.

### 3. Build an access package

Create catalog + access package bundling 1 group + 1 app, requestor = all employees, approval = manager.

### 4. Run an access review

On a privileged role, schedule a quarterly review with the user as the reviewer + auto-deny on no response.

### 5. Add a managed identity to a Function App

Enable system-assigned MI -> grant Storage Blob Data Reader on a storage account -> read a blob from the function code.
