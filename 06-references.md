# SC-300 Concept and Reference Index

> Quick-lookup index of every term, service, and acronym you will see on the exam.

- **Conditional Access** - Policy engine for sign-in conditions
- **Identity Protection (P2)** - Risk detection + automated remediation
- **PIM** - JIT role activation
- **Entitlement Management** - Self-service access packages
- **Access Reviews** - Recertification campaigns
- **Lifecycle Workflows** - JML automation
- **Continuous Access Evaluation** - Token revocation enforcement
- **Workload Identities P2** - CA + IP for service principals
- **App Proxy** - Reverse proxy for on-prem web apps
- **Authentication Strength** - Granular MFA enforcement
- **Cross-tenant Access Settings** - B2B inbound/outbound posture
